## Colima (Docker runtime)

Auto-start Colima at login via LaunchAgent. Handled by `install-macos` automatically.

Starts with: `--cpu 1 --memory 2 --vm-type vz`

Logs: `/tmp/colima.startup.log`, `/tmp/colima.startup.err`
